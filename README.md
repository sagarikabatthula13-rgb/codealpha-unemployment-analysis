Unemployment Analysis with Python
Project Overview
This project analyzes unemployment data in India using Python. The dataset is cleaned, explored, and visualized to identify unemployment trends and patterns.
Objectives
Analyze unemployment rate data.
Perform data cleaning and preprocessing.
Explore unemployment trends across different regions.
Visualize unemployment rates using graphs.
Understand the impact of unemployment over time.
Technologies Used
Python
Pandas
Matplotlib
Dataset
The project uses the Unemployment in India.csv dataset containing:
Region
Date
Frequency
Estimated Unemployment Rate (%)
Estimated Employed
Estimated Labour Participation Rate (%)
Area
How to Run
Install required libraries: pip install -r requirements.txt
Run the Python file: python unemployment_analysis.py
Output
Dataset summary
Average unemployment rate by region
Unemployment trend visualization
